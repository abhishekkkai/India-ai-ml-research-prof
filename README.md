# Indian AI Professors Database

A comprehensive database of 385+ AI/ML professors across 36 top Indian institutes (IITs, IISc, ISI, IIITs).

## Features
- Search & filter by institute, domain, difficulty
- Unique research profiles for each professor
- Key papers, reading paths, and project ideas
- Email contacts and academic links
- Export as CSV/JSON

## Deploy
This is a static site. Deploy to Vercel:
```bash
npm i -g vercel
vercel
```
